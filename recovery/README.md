# Восстановленная версия «Транспорт НСК»

Здесь хранится доступный исходный код исправления импорта маршрутных PDF, сценарии восстановления и регрессионные проверки. Остальные модули берутся из проверенного исполняемого файла версии 1.2.3. Полного исходного проекта в этой ветке нет.

Для сборки на Windows x64 нужны CPython 3.12, `pyinstaller==6.21.0` и оригинальный переносимый `Транспорт НСК.exe` версии 1.2.3. Сценарии проверяют SHA-256 оригинального файла перед извлечением или сборкой.

```powershell
python recovery/transport_recovery.py extract <original-exe> <empty-bundle-path>
python recovery/check_transport.py <bundle-path>
python recovery/build_portable_preview.py <original-exe> <new-preview-exe>
```

Предварительная версия 1.2.4 предназначена для запуска из отдельной рабочей папки. Установщик и подписанная лента автообновлений этим сценарием не формируются.
